# Agent Debug Log in VS Code

## What is Agent Debug Log?

The **Agent Debug Log** (also called Copilot Chat Debug Log) is a detailed session log generated by GitHub Copilot in VS Code. It records all interactions between the agent and VS Code during a chat session, including:

- Tool calls made by the agent (file reads, searches, terminal commands, etc.)
- Prompts sent to the language model
- Model responses and reasoning
- Errors or failures during tool execution
- Timing and token usage information

This log is useful for:

- **Troubleshooting** why Copilot gave an unexpected response
- **Understanding** what tools and context the agent used to produce an answer
- **Reporting bugs** to the GitHub Copilot team with reproducible evidence
- **Auditing** agent behavior in security-sensitive workflows

---

## Where are Debug Logs Stored?

Debug logs are stored as JSON files in the VS Code workspace storage directory:

```
%APPDATA%\Code\User\workspaceStorage\<workspace-id>\GitHub.copilot-chat\debug-logs\
```

Each session generates a separate log file named by session ID (e.g., `9b35265e-00ce-4a8d-9403-9732ba9b6ce5`).

## How to Enable Agent Debug Logging in VS Code

### Method 1: Via VS Code Settings UI

1. Open **Settings** (`Ctrl + ,`)
2. Search for `copilot debug`
3. Enable the setting:  
   **GitHub Copilot Chat › Debug: Enable Debug Logs**  
   (`github.copilot.chat.debug.enabled` → `true`)
4. Restart VS Code or reload the window (`Ctrl + Shift + P` → **Developer: Reload Window**)

### Method 2: Via `settings.json`

Open your `settings.json` (`Ctrl + Shift + P` → **Preferences: Open User Settings (JSON)**) and add:

```json
{
  "github.copilot.chat.debug.enabled": true
}
```

### Method 3: Via Output Panel (Temporary View)

1. Open the **Output** panel (`Ctrl + Shift + U`)
2. Select **GitHub Copilot Chat** from the dropdown
3. This shows a live stream of agent activity for the current session (does not require the setting above)

## How to Access a Debug Log File

### Option 1: Via Command Palette (Recommended)

1. Press `Ctrl + Shift + P` to open the **Command Palette**
2. Type `Open Agent Debug Log`
3. Select **Developer: Open Agent Debug Log**

This opens the current session's JSONL log file directly in the VS Code editor.

> **Command not appearing?** It only shows after debug logging is enabled. Follow the steps below to enable it first.

#### How to Enable the Command

The `Developer: Open Agent Debug Log` command requires debug logging to be turned on:

1. Open `settings.json` (`Ctrl + Shift + P` → **Preferences: Open User Settings (JSON)**)
2. Add the following:
   ```json
   {
     "github.copilot.chat.debug.enabled": true
   }
   ```
3. Reload VS Code (`Ctrl + Shift + P` → **Developer: Reload Window**)
4. Start a new Copilot Chat session to generate a log
5. Now run `Developer: Open Agent Debug Log` from the Command Palette

### Option 2: Navigate Manually

```powershell
# Windows
explorer "$env:APPDATA\Code\User\workspaceStorage"
```

Then find your workspace folder and browse to `GitHub.copilot-chat\debug-logs\`.

## What a Debug Log Contains

A typical debug log entry includes:

| Field | Description |
|---|---|
| `sessionId` | Unique ID for the chat session |
| `turnId` | ID for each user/agent exchange |
| `toolCalls` | List of tools invoked (e.g., `read_file`, `grep_search`) |
| `modelRequest` | The prompt sent to the LLM |
| `modelResponse` | The raw model output |
| `errors` | Any tool failures or exceptions |
| `timestamp` | When each event occurred |

---

## Tips

- Debug logs can grow large in long sessions — disable the setting when not needed.
- Logs may contain file contents and prompts — treat them as sensitive and avoid sharing publicly.
- Use the `VSCODE_TARGET_SESSION_LOG` environment variable (available in agent context) to locate the current session's log file directly.
